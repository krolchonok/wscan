# Совместимость каталога v0.1.2

Снимок локальной runtime-библиотеки от 2026-10-11. Это офлайн-проверка
на текущей машине; наличие интерпретаторов и версия библиотеки влияют на числа.

| Тип | Допущено офлайн | Всего в каталоге | Недоступно |
| --- | ---: | ---: | ---: |
| YAML | 11238 | 11639 | 401 |
| NSE | 543 | 612 | 69 |
| Всего | 11781 | 12251 | 470 |

Проверок на сетевых целях выполнено **0**. Наличие в колонке «допущено»
не подтверждает работу каждого метода или наличие уязвимости. Workflows,
служебные YAML и исключённые локальные аудиты не являются отдельными
проверками удалённого каталога.

[Функции и ограничения движка](SUPPORTED.md). Полный список с причинами
для каждой проверки можно получить локальной командой после скачивания библиотеки.
Его можно получить заново без сканирования целей:

```sh
./wscan audit-library reports/library-audit
```

README.md группирует проверки по сервисам; summary.json содержит общие числа,
compatibility.json — каждый шаблон/NSE и причину отказа. Числа отчёта относятся к установленной версии библиотеки и текущей машине
и могут отличаться от этого исторического снимка v0.1.2.

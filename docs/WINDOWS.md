# Windows x86-64

Сборка: `wscan-VERSION-windows-amd64.zip`. Распакуйте ZIP целиком, включая
`tools` и документацию. Запускайте из PowerShell или Windows Terminal:

```powershell
.\wscan.exe version
.\wscan.exe capabilities
.\wscan.exe library update
.\wscan.exe
```

`start.cmd` запускает тот же EXE из каталога архива и передаёт аргументы.
Автоматического повышения прав нет. Для обычного TCP/HTTP сканирования
права администратора не требуются. Go, C-компилятор, Nuclei и Nmap на машине
пользователя не нужны. Git нужен для скачивания и обновления библиотеки;
Python 3 / Ruby — только для функций, которые их используют.

Настройки, библиотека и SQLite находятся в `%APPDATA%\wscan\`.
Библиотеку можно указать через `$env:WSCAN_LIBRARY_DIR`. При переносе данных
между Linux и Windows сначала закройте приложение и проверьте сохранённые
пути к файлам, словарям, библиотеке и интерфейсам.

## Отличия от Linux

- На Windows обнаружение живых хостов использует доступные сетевые проверки
  и Windows `ping`. Дополнительное подтверждение через Linux neighbor table
  не применяется.
- SMB, LDAP, WinRM и другие клиенты подключаются к удалённым сервисам;
  Windows SMB-служба на машине сканера не нужна для клиентских проверок.
- Локальный приёмник Coerce/Responder требует свободный TCP/445 на выбранном
  адресе и разрешённые входящие подключения. Обычно этот порт занят
  системной SMB-службой Windows. Программа показывает ошибку привязки и
  не останавливает системную службу автоматически. Используйте отдельный
  приёмник со свободным портом. Автоматическое освобождение/восстановление
  порта реализовано только для Linux.
- Запуск Linux shell-команд в `code:`-шаблонах требует подходящего
  интерпретатора/окружения; переносимость EXE не означает переносимость
  каждой команды стороннего шаблона.

## Сборка из исходников

Нужны Git, Go версии из `go.mod`; для упаковки также Python 3.

```powershell
$env:CGO_ENABLED = '0'
go build -buildvcs=false -trimpath -ldflags='-s -w' -o wscan.exe .
.\wscan.exe version
python scripts/package-windows-amd64.py dev
```

Скрипт упаковки работает также на Linux и создаёт ZIP и SHA-256 в `dist`.

Проверка скачанного ZIP:

```powershell
(Get-FileHash .\wscan-VERSION-windows-amd64.zip -Algorithm SHA256).Hash
Get-Content .\wscan-VERSION-windows-amd64.zip.sha256
```

CI запускает `go vet ./...`, `go test ./...` и команды `version` / `capabilities`
из распакованного архива на Windows runner. Проверки рендеринга TUI
автоматизированы; интерактивное управление настоящим терминалом и проверки
против реальных Windows-сервисов требуют отдельного ручного прогона.

# Перенос wscan

Релиз v0.1.4 рассчитан на Linux x86-64, собран без CGO. Go на новом ПК не нужен.
Архив содержит приложение, документацию и согласованный WinPEAS для ручного запуска.
Библиотека проверок скачивается отдельно из https://github.com/krolchonok/wscan-templates.
Внешние Nuclei/Nmap/Metasploit не нужны.

```sh
sha256sum -c wscan-v0.1.4-linux-amd64.tar.gz.sha256
tar -xzf wscan-v0.1.4-linux-amd64.tar.gz
cd wscan-linux-amd64
./start.sh library update
./start.sh
```

Нужны Git и доступ к GitHub при скачивании/обновлении библиотеки. Первый обычный
запуск скачает её автоматически, если локальной библиотеки ещё нет.
После установки интернет для использования локальных проверок не нужен.
Обновление: `./start.sh library update` или общие настройки TUI.
Python/Ruby нужны только функциям, использующим эти интерпретаторы.
WinPEAS автоматически обычным сканированием не запускается.
Windows/macOS этим архивом не поддерживаются.

## Работа без интернета и перенос проектов

Заранее скачайте библиотеку на компьютере с доступом к GitHub. Закройте wscan
и перенесите каталог `~/.config/wscan/` на рабочий Linux-ПК
(при XDG_CONFIG_HOME — `$XDG_CONFIG_HOME/wscan/`). Он содержит библиотеку,
настройки, SQLite, результаты и учётные данные. Для чистой установки достаточно
перенести библиотеку и задать `WSCAN_LIBRARY_DIR=/путь/к/library`.
После переноса проверьте пути в `library-remote.json`, интерфейсы и VPN.
Рабочие данные не входят в релиз и не публикуются в Git.

## Сборка

Нужен Go версии из go.mod; упаковка использует Python 3 и tar.

```sh
./scripts/package-linux-amd64.sh v0.1.4
```

Библиотека для упаковки не требуется. CI скачивает её из отдельного репозитория
только для тестов, запускает go vet и go test; ошибки блокируют публикацию.
Исторические релизы v0.1.0–v0.1.2 остаются архивами со старой схемой комплектации.

Возможности: `./start.sh capabilities` или SUPPORTED.md.
Загрузка сигнатур сервисов: `./start.sh signatures` (офлайн).
После обновления приложения выполните `./start.sh library update`.
После скачивания библиотеки получите офлайн-отчёт без сканирования целей:
`./start.sh audit-library reports/library-audit`.

# Перенос wscan

Релиз рассчитан на Linux x86-64. Приложение собрано без CGO; Go на новом ПК не нужен.
Runtime-библиотека шаблонов/NSE и документация входят в архив.
Бинарники Nuclei/Nmap/Metasploit не входят в v0.1.1+.
WinPEAS включён как согласованное исключение для ручного запуска через MSSQL;
обычный скан его не запускает. p0wny-shell в этот комплект не включён.

```sh
sha256sum -c wscan-v0.1.1-linux-amd64.tar.gz.sha256
tar -xzf wscan-v0.1.1-linux-amd64.tar.gz
cd wscan-linux-amd64
./start.sh
```

Nuclei и Nmap устанавливать не нужно: проверки исполняются нашим движком.
Git нужен для обновления библиотеки,
Python 3 и Ruby — для функций и шаблонов, использующих эти интерпретаторы.
Библиотека обновляется через общие настройки (`p` на экране проектов).
Совместимость отдельных шаблонов и NSE ограничена возможностями движка.
Windows и macOS требуют отдельной сборки и совместимых внешних инструментов.

## Перенос проектов

Закройте wscan и скопируйте весь каталог `~/.config/wscan/` на новый Linux-ПК
(при заданном XDG_CONFIG_HOME — `$XDG_CONFIG_HOME/wscan/`).
В нём находятся база результатов, учётные данные, настройки и скачанные файлы.
Архив релиза этих данных не содержит. После переноса проверьте сохранённые
пути библиотеки и файлов, сетевые интерфейсы и VPN-настройки.

## Сборка

Нужен Go версии из go.mod; скрипт упаковки использует Python 3 и tar. Исходники отделены от библиотеки проверок.

```sh
# Для полного комплекта возьмите library/ из первоначального релиза v0.1.0.
# Публичный репозиторий содержит только Nuclei-шаблоны.
./scripts/package-linux-amd64.sh v0.1.1
```

Результат и SHA-256 находятся в dist/. Git-теги v* запускают сборку и публикацию
предварительного релиза в приватном репозитории через GitHub Actions.
CI восстанавливает полную runtime-библиотеку из первого приватного релиза v0.1.0:
публичный репозиторий шаблонов не содержит Nmap/NSE.
Результат полного прогона тестов указывается в описании релиза. Рабочие данные в Git не добавляются.

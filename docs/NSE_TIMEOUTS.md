# Таймауты NSE

Сетевой timeout проекта ограничивает отдельную сетевую операцию. Общий лимит одного запуска NSE-скрипта на всех выбранных портах равен `max(30 секунд, 3 × сетевой timeout)`. При timeout проекта 10 секунд скрипт получает 30 секунд.

Лимит действует на загрузку и выполнение Lua, повторные соединения и нативные проверки учётных данных. Lua использует контекст с дедлайном; сетевые операции ограничены тем же дедлайном. В конфигурации движка `nse.Config.ScriptTimeout` можно задать явный общий лимит.

При истечении лимита ошибка содержит имя скрипта и длительность лимита. Скан продолжает выполнять остальные скрипты. Отмена всего скана сохраняет своё действие.

Журнал и текущий этап показывают хост, имя скрипта, запуск с лимитом и завершение с длительностью и статусом: завершён, пропущен, ошибка, таймаут или отменён. Ошибка выполнения выводится сразу после завершения проверки.

Изменения начинают действовать после перезапуска приложения: уже запущенный процесс продолжает работать со старым кодом.

# Результаты

`5` открывает список результатов всего проекта.
Из колонки хоста/порта `Enter` открывает тот же экран в выбранной области;
из истории — выбранный запуск, из задачи — её сохранённый запуск.
Просмотр и удаление доступны во всех этих входах. Область указана в заголовке. По умолчанию показаны риски,
ошибки и сводки Coerce. Информационные результаты доступны по `i`.

- `↑/↓`, `PgUp/PgDn`, `Home/End` — выбрать строку.
- `Enter` — открыть карточку; `Esc` — вернуться к списку.
- В карточке `↑/↓`, `PgUp/PgDn` — прокрутка, `r` — полный технический отчёт.
- `/` — поиск, `f` — фильтр, `i` — все результаты, `c` — основной список.
- `Space` — отметить строку; `a` — отметить/снять все видимые строки.
- `Del`, `Backspace`, `d` — удалить отмеченные строки, без отметок — текущую.
- `D` — удалить весь видимый список, с учётом фильтра и поиска.

Удаление требует подтверждения: `Enter`/`y` — удалить, `Esc`/`n` — отменить.
Из базы текущего проекта удаляются выбранные детекты и их старые копии во
всех запусках. Удаление сводки Coerce удаляет и её исходные события. Хосты,
службы и другие проекты сохраняются. Результаты, появившиеся после показа
подтверждения, сохраняются. Новая проверка может обнаружить детект снова;
уже экспортированные файлы не изменяются.

События Coerce/Responder сгруппированы по машине. Вывод строится по последнему
сохранённому отчёту Coerce: старый ответ NTLM не выдаётся за успех более новой
проверки. Полный сохранённый журнал доступен по `r`. Анонимный Authenticate
показывается отдельно от непустого ответа; получение доступа не подразумевается.

В карточке задачи по умолчанию показан итог; `r` раскрывает технический
журнал. `?` показывает помощь текущего экрана с прокруткой. Статус
«завершён» относится к задаче, а не к подтверждению уязвимости.

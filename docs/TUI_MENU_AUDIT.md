# Аудит повторов меню TUI

Проверены определения пунктов, обработчики выбора и возвраты всех экранов TUI, а также группировка и выбор проверок в каталоге. Это аудит навигации по исходникам; сетевые действия при проверке не запускались.

Критерий повтора: одинаковое действие над одинаковой областью, показанное как независимые инструменты. Проект, подсеть, выбранная машина, порт, конкретный запуск и открытая сессия — разные области. Переход назад, выбор учётки в форме подключения и возврат к результату задачи сохраняются.

## Исправления

- На корневом экране «Назад» не повторяет «Проекты»; AD и проверки используют один пункт возврата в боковом меню.
- AD-разведка доступна через раздел AD; обычный мастер её не предлагает.
- AD-проверки и Coerce удалены из общего списка взаимодействий.
- Coerce и управление Responder показываются в отдельной форме Coerce; LDAP/Kerberos/SYSVOL/BloodHound не повторяют эти пункты.
- CVE по версиям и пакет NSE vuln перенесены из взаимодействий в раздел проверок проекта.
- Старые обзор проекта и меню машины используют текущий экран машин вместо самостоятельных повторных списков действий.
- MSSQL показывает один список действий. Повторная панель числовых команд над результатами убрана; дополнительные аудиты доступны в том же меню.
- PostgreSQL/MySQL не повторяют одни действия одновременно в числовой панели, подсказках и списке SQL-алиасов.
- Одна форма Coerce сохраняет выбор конкретной машины и групповой области проекта.
- В каталоге повторный путь проверки не размножает строки, счётчики групп и список выбранных ID. Повторные названия Web-групп нормализованы.

## Проверенные категории

| Категория | Основное место / различие областей |
|---|---|
| Проекты, создание, удаление, запуск Web | Начальный экран проектов; Web — другой интерфейс, не ещё один инструмент |
| Машины, подсети, выбор хостов и портов | Рабочий экран и выбор области; групповой выбор не запускает отдельный скан |
| Обнаружение живых машин, портов, PTR, идентификация версий | Запуск сканирования выбранной области; ARP/ICMP/TCP, DNS PTR и версии — разные операции |
| Полный скан и проверки известных сервисов | Различаются наличием этапа discovery; один маршрут выбора проверок |
| AD-разведка | AD → Разведка AD; старый старт AD с созданием проекта отличается созданием проекта |
| LDAP-аудит, AS-REP кандидаты, SYSVOL, LDAP signing, BloodHound | AD → Проверки AD; разные результаты и параметры |
| Coerce, RPC discovery, Responder | AD → Coerce / Responder; запуск приёмника, RPC-пробы и обратная аутентификация — разные операции |
| Библиотека проекта, CVE, пакет NSE vuln | Проверки проекта; выбор шаблонов, офлайн-сопоставление и запуск пакета — разные операции |
| Каталог: сервисы, продукты, типы, воздействие, базы данных, поиск | Представления одного каталога, идентичность проверки — путь файла |
| SMB | Взаимодействие → SMB; null/guest/учётка — режимы одного подключения |
| FTP/FTPS | Один проводник; FTP, explicit/implicit TLS — режимы подключения |
| WinRM | Один вход; проводник, ACL, отдельная команда и сохраняющая состояние сессия — разные действия |
| MSSQL | Один список действий; базы/таблицы/SQL, настройки xp_cmdshell, передача, запуск WinPEAS и чтение отчёта — разные операции |
| PostgreSQL, MySQL/MariaDB | Подключение и общий SQL-проводник; текущая база и выбранная таблица задают область |
| Web discovery, словари | Один поиск путей; выбор словаря — параметр |
| Web LFI, SQLi, Upload | Разные формы и разные проверки, не взаимозаменяемые инструменты |
| SSH и словари | SSH-режим и его параметры; отдельная проверка сохранённых credentials отличается от словаря |
| Kyocera | Один инструмент чтения адресной книги |
| Credentials, проверки входа, post-auth | Хранилище учёток, попытки входа и действия подтверждённой учётки — разные стадии |
| Post-auth SMB/WinRM/SQL-модули | Фиксированные операции после входа; проводники и произвольные консоли имеют другое поведение |
| Задачи, итоги, журнал, отмена | Один список задач; итог и журнал — представления одной задачи |
| Результаты, карточка, доказательства, история, удаление, экспорт | Одна система результатов; фильтр хоста/порта/запуска сохраняет отдельную область |
| Настройки проекта, скорости, профили, параметры разового запуска | Значения по умолчанию отличаются от параметров конкретного запуска; общий профиль задаёт сразу несколько лимитов |
| Библиотека приложения, зависимости | Общие настройки; установка библиотеки отличается от выбора проверок проекта |
| Подтверждения, ввод, справка | Служебные экраны, не повторные инструменты |
| Статический макет cmd/tui-navigation-demo | Отдельный демонстратор без исполнителей и базы; не меню рабочего TUI |

## Проверка

Пакетные тесты TUI проверяют маршруты, границы области, отсутствие AD/CVE/NSE в меню подключений, отсутствие Coerce в LDAP/Kerberos/SYSVOL, уникальность ID в каталоге и доступность меню при разных размерах терминала. Проверяются сборки рабочего preview и отдельного статического demo.

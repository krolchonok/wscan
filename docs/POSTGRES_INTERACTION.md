# PostgreSQL во «Взаимодействии»

Выбери хост → «Взаимодействие» → PostgreSQL. При выборе обнаруженного сервиса PostgreSQL используется его TCP-порт, включая нестандартный.

Enter подключает выбранную сохранённую учётку типа «пароль» (пароль может быть пустым). Первая строка подключает без пароля с ролью `postgres`; `u` меняет имя роли. Это доступ без пароля для указанной роли, а не отдельная анонимная учётка.

В настройках: `c` — сохранённые учётки, `p` — порт, `b` — база, `s` — TLS (`require`, `verify-full`, `disable`). По умолчанию TLS обязателен; `verify-full` проверяет сертификат и имя сервера, `disable` подходит для серверов без TLS.

После входа: `1` — пользователь и версия, `2` — базы, `3` — таблицы, `4` — столбцы, `5` — строки, `b` — подключиться к другой базе, `c` — SQL или алиас:

- `:db`
- `:tables`
- `:columns public.users`
- `:rows public.users 100` (1–500 строк)
- `:count public.users`

SQL поддерживает один SELECT, WITH или EXPLAIN в транзакции только для чтения, которая всегда откатывается. Вывод ограничен 500 строками. Права роли определяют доступные данные. Имена со сложным экранированием можно использовать в SQL; алиасы принимают простые имена schema.table.

Esc отменяет операцию и закрывает сессию. Попытки подключения записываются и учитывают лимит ошибок входа проекта.

## Интерактивный просмотр

После подключения открывается список таблиц; MySQL без выбранной базы сначала показывает базы. Выбирай стрелками ↑/↓ и нажимай Enter: база → таблицы → данные таблицы. В консоли Enter или `3` открывает таблицы, `2` или `b` — базы.

Данные показываются по 100 строк: ←/→ (или p/n) — предыдущая/следующая страница, ↑/↓ и PgUp/PgDn — прокрутка вывода, `c` — список столбцов, `r` — обновить данные. Esc из данных возвращает к таблицам, из списка — в SQL-консоль. `s` из списка открывает ввод SQL.

Если список пуст, проверь выбранную базу и права учётки. Списки баз и таблиц ограничены 500 записями. Страницы читаются отдельными запросами без фиксированной сортировки; при изменении таблицы между запросами строки могут смещаться.

Данные отображаются сеткой с одинаковой шириной столбцов. Длинные значения переносятся внутри ячеек. Если все столбцы не помещаются, клавиши `[` и `]` сдвигают видимые столбцы.

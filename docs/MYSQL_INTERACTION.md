# MySQL / MariaDB во «Взаимодействии»

Выбери хост → «Взаимодействие» → MySQL / MariaDB. Выбранный обнаруженный MySQL-сервис автоматически подставляет свой TCP-порт, включая нестандартный.

Первая строка — вход с пустым паролем; `u` меняет имя пользователя (по умолчанию `root`, можно оставить пустым для проверки анонимной учётки). Другие строки — сохранённые учётки типа «пароль», включая пустые пароли. `c` открывает управление учётками.

Настройка: `p` — TCP-порт, `b` — база (пустое значение означает подключение без выбранной базы), `s` — TLS. По умолчанию `true` требует TLS и проверяет сертификат; `skip-verify` требует TLS без проверки сертификата; `false` отключает TLS. Enter выполняет одну попытку подключения с учётом лимита ошибок входа проекта.

После входа: `1` — пользователь, база и версия; `2` — доступные базы; `3` — таблицы выбранной базы; `4` — столбцы; `5` — строки; `b` — сменить базу; `c` — SQL или алиас.

- `:db`
- `:tables`
- `:columns users` или `:columns app.users`
- `:rows users 100` (1–500 строк)
- `:count users`

Консоль принимает один SELECT, WITH, EXPLAIN, SHOW или DESCRIBE. Каждый запрос выполняется в транзакции READ ONLY с последующим откатом; вывод ограничен 500 строками. SELECT INTO, несколько SQL-операторов и исполняемые SQL-комментарии запрещены. В строковых литералах используй удвоенные кавычки вместо обратного слеша. Доступ к данным определяется правами выбранной учётки.

Esc отменяет операцию и закрывает сессию. При ошибке переключения базы предыдущая сессия сохраняется.

## Интерактивный просмотр

После подключения открывается список таблиц; MySQL без выбранной базы сначала показывает базы. Выбирай стрелками ↑/↓ и нажимай Enter: база → таблицы → данные таблицы. В консоли Enter или `3` открывает таблицы, `2` или `b` — базы.

Данные показываются по 100 строк: ←/→ (или p/n) — предыдущая/следующая страница, ↑/↓ и PgUp/PgDn — прокрутка вывода, `c` — список столбцов, `r` — обновить данные. Esc из данных возвращает к таблицам, из списка — в SQL-консоль. `s` из списка открывает ввод SQL.

Если список пуст, проверь выбранную базу и права учётки. Списки баз и таблиц ограничены 500 записями. Страницы читаются отдельными запросами без фиксированной сортировки; при изменении таблицы между запросами строки могут смещаться.

Данные отображаются сеткой с одинаковой шириной столбцов. Длинные значения переносятся внутри ячеек. Если все столбцы не помещаются, клавиши `[` и `]` сдвигают видимые столбцы.

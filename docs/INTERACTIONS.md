# Взаимодействие проекта

В навигации проекта теперь четыре пункта: **1 Подсети**, **2 Хосты**, **3 Задачи**, **4 Взаимодействие**. Клавиша `4` открывает меню из любого из этих разделов; `i` на выбранном хосте/порту остаётся быстрым переходом.

В меню взаимодействия `h` открывает список хостов проекта. ↑/↓ выбирают инструмент, Enter открывает его. Доступны SMB, WinRM, MSSQL, LFI, FTP, PostgreSQL, MySQL / MariaDB и Web — поиск каталогов и файлов. При открытии с выбранного веб-сервиса подставляется его URL и порт.

## Поиск веб-каталогов и файлов

Открой **4 Взаимодействие → Web — поиск каталогов и файлов по словарю**.

- `u` — HTTP/HTTPS URL, включая базовый каталог.
- `w` — выбрать словарь SecLists; `/` ищет по имени, `p` позволяет ввести путь к своему файлу. Встроенный короткий список тоже доступен.
- `x` — расширения через запятую (`php,html,txt`): проверяются исходные слова и варианты с расширениями.
- `v` — virtual host (HTTP Host).
- `f` — интересующие HTTP-статусы. По умолчанию: 200, 204, 301, 302, 307, 308, 401, 403.
- `z` — исключаемые размеры ответов в байтах, через запятую.
- `r` — RPS; 0 означает до 100 запросов в секунду.
- `c` — параллельность, 1–64.
- `t` — проверка TLS-сертификата (по умолчанию включена).
- `a` — автоматический wildcard-фильтр (по умолчанию включён).
- `s` — запустить, Enter — детали найденного пути, `e` — CSV.

Результаты и прогресс появляются во время запуска. Esc останавливает перебор; после завершения Esc возвращает в меню взаимодействия. Найденные пути сохраняются в истории проекта, включая частичные результаты остановленного запуска. Перенаправления записываются без перехода по ним.

Wildcard-фильтр сравнивает ответы на два случайных несуществующих пути, нормализуя отражённый путь и учитывая Location. Динамические страницы могут потребовать ручного фильтра размера или отключения автоматического фильтра. Для сравнения читается до 1 МиБ тела ответа; размер берётся из Content-Length, если он указан.

Этот режим перебирает каталоги и файлы. Перебор DNS-поддоменов и virtual hosts отдельным словарём пока не реализован; поле `v` задаёт один Host для текущего запуска.

## SecLists

Веб-словари установлены из официального https://github.com/danielmiessler/SecLists в `~/.config/wscan/wordlists/SecLists`. Используется раздел `Discovery/Web-Content`; остальные разделы не скачиваются. Если SecLists найден, новым веб-запускам подставляется `common.txt`. В выборе словаря первыми идут common и небольшие raft-списки.

Также автоматически распознаются установки в `/usr/share/seclists` и `/usr/share/wordlists/SecLists`. Для обновления локальной копии:

```sh
git -C ~/.config/wscan/wordlists/SecLists pull --ff-only
```

## SSH — словарный перебор

В **4 Взаимодействие → SSH — словарный перебор учёток** работает встроенный движок; внешний Hydra не требуется. С выбранного SSH-сервиса автоматически подставляется его порт.

- `u` — один пользователь.
- `l` — файл пользователей, по одному имени на строку; пустое значение возвращает режим одного пользователя.
- `p` — выбор словаря паролей (RockYou), `f` — свой файл. Пробелы в паролях сохраняются; пустая строка проверяет пустой пароль.
- `t` — TCP-порт.
- `r` — общий RPS SSH-перебора (по умолчанию 5; 0 — без ограничения скорости).
- `c` — число потоков, 1–64 (по умолчанию 4).
- `d` — минимальный интервал запуска попыток в миллисекундах (по умолчанию 0).
- `s` или Enter — запуск.
- Esc — остановка; после завершения — возврат в меню.
- `a` на успешной строке — сохранить найденную учётку в проект.

Режим требует включённых credential-атак в настройках проекта. При включённом лимите (клавиша `b`) перед каждой попыткой учитывается общий журнал ошибок пользователя по всему проекту. Стандартный лимит проекта — 3 ошибки за 30 минут; изменить его можно в настройках проекта. Достижение лимита отмечается как пропуск, а не как доказательство отсутствия пароля в словаре.

Очередь: один пароль на всех активных пользователей, затем следующий пароль. При параллельном выполнении порядок завершения может отличаться. После успеха пользователь исключается из перебора; при включённом лимите — также после его достижения. Выполняется одна password-аутентификация за попытку, без повторения через keyboard-interactive; учётные записи, поддерживающие только keyboard-interactive, этим режимом не проверяются. Сетевые и протокольные ошибки останавливают запуск. RPS задан отдельно для SSH и ограничивает суммарное число запусков попыток всех потоков. Дополнительная пауза `d` задаёт минимальный интервал; действует более медленное из двух ограничений. При включённом лимите проекта попытки одного пользователя сериализуются. После успеха новые попытки для пользователя не запускаются, а активные SSH-подключения отменяются. Перебор остальных пользователей продолжается.

Строки выполненных попыток показывают проверенный пароль в кавычках, включая неуспешные попытки. В постоянном журнале пароли не сохраняются. История попыток находится в общем журнале credential-атак; учётка добавляется в список проекта только клавишей `a`.

RockYou установлен из SecLists и доступен как `/usr/share/wordlists/rockyou.txt`. При открытии SSH-перебора он выбирается по умолчанию. Файл читается построчно; весь словарь не загружается в память. Клавишей `b` можно включить лимит проекта для попыток.

SSH-перебор теперь по умолчанию работает без ограничения числа попыток. Клавиша `b` переключает между этим режимом и лимитом проекта. Журнал входов продолжает записываться в обоих режимах; остановка после успешного входа и Esc сохраняются.

# Возможности wscan

Проверки выполняются нашим Go/JavaScript/Lua-движком. Внешние Nuclei,
Nmap и Metasploit не используются. Обычные утилиты и интерпретаторы разрешены.
WinPEAS — согласованное исключение, только ручной запуск с AllowExploit.

## Поддерживается

| Возможность | Реализация и границы |
| --- | --- |
| Проекты, цели, история, находки, задачи | TUI, SQLite, отмена, ограничения скорости и параллельности |
| Экспорт | JSON, HTML, CSV |
| TCP discovery | Connect scan, общие/Top-N/пользовательские порты, диапазон 1–65535 |
| UDP discovery | Пробы; открытым считается только ответивший порт |
| Сервисы и версии | Протокольные пробы и баннеры; не вся база сигнатур Nmap |
| CIDR, живые хосты и имена | ICMP с fallback ping, DNS/PTR, выбор сетевых интерфейсов |
| AD-аудит | LDAP/DNS SRV, SMB/RDP-метаданные, предварительные признаки конфигурации и AD CS |
| HTTP/HTTPS | method/path/raw, заголовки, body, variables, payloads |
| HTTP-сессии | cookie-reuse; disable-cookie; cookies изолированы по шаблону и цели |
| HTTP-редиректы | redirects/host-redirects, max-redirects; только тот же хост и выбранный порт; по умолчанию выключены |
| HTTP-ограничения | stop-at-first-match, max-size (по умолчанию 1 МиБ), disable-path-automerge |
| Матчеры | status, word, regex, binary, DSL, size, XPath; комбинации и отрицания |
| Экстракторы | regex, kval, DSL, JSON (ограниченный jq), XPath |
| Payloads | Inline/файловые; batteringram, pitchfork, clusterbomb с лимитом комбинаций |
| TCP/network, DNS, TLS | Собственные исполнители; сертификаты и реализованные параметры TLS |
| Workflows и flow | Поддержанные сценарии через собственный исполнитель и встроенный goja |
| JavaScript | Встроенный goja, init/pre-condition, аргументы, exports и реализованные API |
| JS-модули | net, bytes, ssh, redis, mysql, postgres, smb, mssql, fs, vnc, rdp, ldap — реализованный поднабор API, не весь SDK Nuclei |
| NSE | Встроенный gopher-lua, наши сетевые модули и совместимые nselib; проверка импорта не гарантирует поддержку каждого action |
| SMB | Browse, чтение файлов/шар и ограниченный поиск конфигураций |
| FTP/FTPS | Browse, предпросмотр, скачивание, экспорт; проверка TLS |
| MySQL/PostgreSQL/MSSQL | Подключение и реализованные действия чтения/аудита; команды отдельно разрешаются |
| WinRM | Подключение, реализованные файловые действия и PowerShell на целевой ОС |
| credentials | Хранение, поддержанные проверки входа/перебор с ограничениями попыток |
| Web Discovery | Поиск путей, расширений и vhosts, фильтры ответов и wildcard, собственные HTTP-запросы |
| SQLi в формах | Реализованные проверки ошибок/сравнений/задержек; не весь набор SQLmap, отдельно AllowExploit |
| Web LFI | Ограниченные пробы одного URL/query-параметра, отдельно AllowExploit |
| File upload | Проверка формы/загрузки и исполнения маркера; не автоматическая установка веб-шелла |
| Kyocera | GET/WSDL-проверка интерфейса и отдельное реализованное действие экспорта адресной книги |
| code: | Python/Ruby/bash и другие найденные интерпретаторы; отдельно AllowCodeExec; запрещённые внешние сканеры не являются допустимой обёрткой |
| MSSQL передача файла | Python HTTP-сервер одного файла, контроль SHA-256, отдельное разрешение |
| WinPEAS | Готовый инструмент из комплекта; ручной запуск на Windows через MSSQL |

## Ограничено или не поддерживается

| Возможность | Статус |
| --- | --- |
| Полная совместимость с Nuclei/Nmap | Не заявляется; внешнего fallback нет |
| JS oracle/rsync/smtp | Не реализованы; require() отклоняется, каталог показывает причину |
| Неизвестные JS-модули / динамический require() | Отклоняются офлайн; отсутствие статически найденной проблемы не гарантирует выполнение всех методов |
| headless, websocket, whois | Не поддерживаются |
| file, локальные/self-contained аудиты | Не выбираются для проверок удалённых хостов |
| HTTP pre-condition, global-matchers | Не реализованы; непустые/включённые настройки отклоняются |
| HTTP digest-username/digest-password | Не реализованы; непустые значения отклоняются |
| HTTP req-condition, iterate-all, read-all | Не реализованы; включённые настройки отклоняются |
| HTTP редирект на другой хост/порт | Не выполняется: сохраняется выбранная область |
| Полный raw unsafe/fuzzing/headless SDK | Не поддерживается; raw — обработка реализованных HTTP-форм, не произвольный транспорт |
| Полный jq и все DSL-функции | Только реализованный набор |
| OAST / interactsh | Собственный HTTP-callback; не полный DNS/SMTP/HTTP сервис Interactsh; доступность callback должна быть настроена |
| UDP без ответа | Нельзя отличить open/filtered; отсутствие результата не означает закрытый порт |
| Полный Nmap NSE API | Не все модули, корутины и методы реализованы; несовместимые импорты/ошибки показываются |
| Kerberoasting/AS-REP находки AD-аудита | Предварительные LDAP-признаки, не автоматическое получение/взлом хешей |
| p0wny-shell | Справочный сторонний файл, не включён в релиз и не запускается движком |
| Windows/macOS release | Текущий готовый архив только Linux x86-64; переносимость исходников не равна проверенной сборке для другой ОС |

## Как получить список

`wscan capabilities` выводит эту таблицу без открытия базы или сетевых запросов.
`wscan audit-library OUTPUT_DIR` проверяет установленную библиотеку офлайн и
создаёт README.md, summary.json и compatibility.json с причинами недоступности.

В summary.json `native_compatible` означает допуск по офлайн-проверке,
а `target_executions_verified` всегда равен 0: каталог ничего не сканирует.
Реальное выполнение требует выбранной цели, доступов, разрешений и проверки
ошибок задачи. Нет находок — не доказательство отсутствия уязвимостей.
Покрытие каталога зависит от версии библиотеки и доступных интерпретаторов.

Семантика HTTP-полей сверена с описанием исходного формата:
[описание HTTP-полей](https://github.com/projectdiscovery/nuclei/blob/dev/SYNTAX-REFERENCE.md).

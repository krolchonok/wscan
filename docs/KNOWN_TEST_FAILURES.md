# Проверки и ограничения v0.1.2

`CGO_ENABLED=0 go test ./...` и `CGO_ENABLED=0 go vet ./...` проходят.
Шесть сбоев, отмеченных в v0.1.0/v0.1.1, воспроизведены и исправлены:
тестовые SSH/Redis/SMB-серверы слушали случайные порты, а тесты выбирали цель
без порта. Движок сохранял область выбранного сервиса и не использовал
подменённый Port из шаблона. Теперь тесты явно выбирают адрес своего сервера.
Производственная привязка к выбранному хосту/порту сохранена и проверяется.

Добавлены проверки реально исполняемых HTTP-параметров, изоляции cookies,
запрета внешних движков, отклонения неподдержанных JS-модулей и честного
офлайн-отчёта. Устранена преждевременная отмена контекста при чтении HTTP-тела.
Отдельная ошибка формата IPv6-адреса в Go-агенте исправлена через JoinHostPort.

Тесты используют локальные синтетические серверы. Это не проверка всех
шаблонов против реальных уязвимых сервисов. Релиз остаётся предварительным;
ограничения и неподдержанные возможности перечислены в SUPPORTED.md.
В CI ошибки тестов и go vet теперь блокируют публикацию.
Имя файла сохранено для совместимости со старыми ссылками.

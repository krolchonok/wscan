# Исходники внешних инструментов

`getKyoceraCreds/` — скачанный репозиторий https://github.com/ushst/getKyoceraCreds.
Он хранится отдельно от исполняемой библиотеки проверок. Установочные скрипты,
Python, Metasploit и исходный Nuclei шаблон автоматически не запускаются.

В wscan добавлена отдельная GET-проверка `kyocera-netviewer-address-book-interface`
для HTTP(S) сервиса TCP 9091. Она читает только WSDL, не создаёт экспорт и не
запрашивает адресную книгу или пароли. Если WSDL не опубликован через GET,
эта проверка не сможет определить интерфейс.

Существующий CVE-2022-1026 шаблон создания экспорта отмечен `exploit`, чтобы
требовать отдельного разрешения эксплуатации в проекте.

`shell.php` из официального релиза p0wny@shell (однофайловый PHP-веб-шелл с
браузерным терминалом), сохранён без изменений.

Источник: https://github.com/flozz/p0wny-shell/releases/tag/v2023.08.10

Версия, URL и SHA-256 сохранены в source.json.

## Для чего

Full-fledged payload для ручной постэксплуатации после того, как
`Web Upload — проверка загрузки PHP-файлов (RCE)` (или ручная проверка)
подтвердила unrestricted file upload с выполнением PHP. Маркерный пробник
движка (`internal/engine/file_upload.go`) только доказывает факт RCE и ничего
не оставляет на сервере намеренно; этот файл — следующий шаг, если нужна
реальная сессия (команды, браузер файловой системы, аплоад/даунлоад).

## Важно

- **Без какой-либо авторизации** — файл отдаёт шелл всем, кто знает URL.
  Переименуй перед загрузкой в что-то неугадываемое и удали сразу после
  использования.
- Используй только в рамках авторизованного теста (как здесь — Hackviser и
  подобные лабы/контракты).
- PHP ≥ 5.3, работает и под Apache/nginx+PHP-FPM.
